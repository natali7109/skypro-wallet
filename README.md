# Skypro.Wallet — Учёт личных расходов

**Skypro.Wallet** — это веб-приложение для учёта личных расходов. Позволяет добавлять, удалять и анализировать расходы по категориям с наглядной визуализацией в виде диаграммы.

🔗 **Деплой:** [нет]  
📁 **Репозиторий:** [https://github.com/natali7109/skypro-wallet](https://github.com/natali7109/skypro-wallet)

---

## 🚀 Функциональные возможности

- 🔐 **Авторизация и регистрация** — вход и создание аккаунта с сохранением данных.
- 📋 **Управление расходами** — добавление, просмотр и удаление транзакций.
- 📊 **Аналитика** — визуализация расходов по категориям за выбранный период.
- 🗓️ **Календарь** — удобный выбор периода для анализа.
- 📱 **Адаптивный дизайн** — в работе.
---

## 🚀 Технологии

- **Vue 3** — Composition API, `<script setup>`
- **Vue Router** — навигация и защита маршрутов
- **Pinia** — управление состоянием
- **Axios** — HTTP-запросы
- **date-fns** — работа с датами
- **Vite** — сборка проекта

## 🛠️ Установка и запуск

```bash
# Клонировать репозиторий
git clone https://github.com/natali7109/skypro-wallet.git

# Перейти в папку проекта
cd skypro-wallet

# Установить зависимости
npm install

# Запустить в режиме разработки
npm run dev

Как пользоваться:
Зарегистрируйтесь или войдите в аккаунт.

На странице «Мои расходы» добавьте новый расход, выбрав категорию и указав сумму.

Все расходы отображаются в таблице, их можно удалять.

На странице «Анализ расходов» выберите период в календаре, чтобы увидеть диаграмму расходов по категориям.
